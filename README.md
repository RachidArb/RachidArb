## 🚀 Featured Engineering Projects

### 1. Enterprise Task Management System (Flagship)
> **Production-grade collaborative platform with layered clean architecture, stateless JWT security, PostgreSQL, and multi-stage Docker containerization.**

* **Technologies**: `Java 21 LTS` • `Spring Boot 3.3.5` • `PostgreSQL 16` • `React 18` • `TypeScript` • `Tailwind CSS` • `Docker Compose` • `Flyway` • `GitHub Actions`
* **Engineering Highlights**:
  * **Layered Domain Architecture**: Clean separation of concerns between HTTP Controllers, Domain Services, Persistence Repositories, DTOs, and Entity models.
  * **Stateless Security**: HMAC-SHA256 signed JWT Bearer authentication with `BCrypt` password hashing (cost factor 12) and method-level authorization guards (`@PreAuthorize`).
  * **Multi-Tenant Data Fencing**: Strict project membership validation preventing cross-tenant access to unauthorized tasks and comment streams.
  * **Database Versioning**: Deterministic schema evolution, foreign key constraints, and performance indexes managed via **Flyway** (`V1__init_schema.sql`).
  * **Rigorous Automated Testing**: **114 automated backend tests** (64 Mockito unit tests + 50 MockMvc integration tests) with 100% pass rate, plus **7 Vitest frontend tests** and **12 end-to-end verification flows**.
  * **Production Containerization**: Multi-stage Docker builds, Nginx reverse proxy configuration, unprivileged container execution, and automated CI on GitHub Actions.
* **Repository**: [github.com/RachidArb/enterprise-task-management-system →](https://github.com/RachidArb/enterprise-task-management-system)

## 🏛️ Engineering Principles

* **Clean Architecture & SOLID**: Strict separation of domain rules from infrastructure, web frameworks, and delivery mechanisms.
* **Test-Driven Reliability**: Automated unit testing for business logic (Mockito) and integration slice testing for HTTP/persistence layers (MockMvc).
* **Defense-in-Depth Security**: Stateless JWTs, strong password hashing (BCrypt), role-based method guards, and hardened container runtimes.
* **Predictable Database Migrations**: Versioned database migrations with Flyway for deterministic deployments and schema integrity.
* **Automated CI/CD**: Automated testing, linting, and container build verification on every commit via GitHub Actions.
